# ts-speed

Сайт для телефона и ПК, который:

1. **Скачивает видео** с TikTok (без водяного знака), YouTube / Shorts и Instagram Reels. Качество можно выбрать от 4K до 360p, а ещё скачать видео без звука или только звук в MP3.
2. **Скачивает треки Spotify** в MP3 по ссылке на трек: название, исполнитель, альбом и обложка берутся из Spotify, а сам звук из этого же трека на YouTube (Spotify шифрует музыку, напрямую её скачать нельзя). Альбомы и плейлисты пока не поддерживаются.
3. **Оценивает эдиты** от 1 до 10: браузер вырезает из ролика 12 кадров, а Claude пишет оценку, сильные и слабые стороны и советы.
4. **Работает 24/7** на бесплатном тарифе Vercel. Сайт можно установить на телефон как приложение: «Добавить на главный экран» в Safari или «Установить приложение» в Chrome.

Старая версия в виде Telegram-бота лежит в папке [telegram-bot/](telegram-bot/).

## Как выложить сайт (GitHub + Vercel, бесплатно)

### 1. Залить код на GitHub

1. Зарегистрируйся на <https://github.com> (если ещё нет аккаунта).
2. Нажми **New repository**, назови его `ts-speeds`, выбери **Private** и нажми **Create repository**. Галочки «Add README» не ставь.
3. В папке проекта выполни (вместо `ТВОЙ_НИК` подставь свой ник на GitHub):

```bash
git remote add origin https://github.com/ТВОЙ_НИК/ts-speeds.git
git push -u origin main
```

При первом `push` откроется окно входа в GitHub: войди в браузере.

### 2. Подключить Vercel

1. Зайди на <https://vercel.com> и нажми **Sign Up → Continue with GitHub**. Тариф выбери **Hobby** (бесплатный).
2. Нажми **Add New → Project** и выбери репозиторий `ts-speeds` → **Import**.
3. Ничего не меняй и нажми **Deploy**. Vercel сам найдёт API в папке `api/` и сайт в папке `public/`.
4. Через 1–2 минуты появится адрес вида `ts-speeds.vercel.app`. Это и есть твой сайт.

Дальше каждый `git push` будет автоматически обновлять сайт.

### 3. Включить оценку эдитов (необязательно)

Без ключа сайт только скачивает видео, а вместо оценки пишет, что она не подключена.

В Vercel открой **Project → Settings → Environment Variables** и добавь переменные:

| Переменная | Что это |
|---|---|
| `ANTHROPIC_API_KEY` | Ключ Claude API с <https://console.anthropic.com/settings/keys>. Это платно: одна оценка стоит примерно 2–4 цента |
| `ACCESS_CODE` | Любой код. Если его задать, оценка будет работать только у тех, кто знает код, и чужие люди не потратят твой баланс |

После добавления переменных открой **Deployments → ⋯ → Redeploy**.

## Instagram и YouTube: cookies

С серверов Vercel Instagram почти всегда, а YouTube иногда требуют вход в аккаунт. Как это обойти:

1. Поставь в браузер расширение **Get cookies.txt LOCALLY** и зайди в Instagram или YouTube под **запасным** аккаунтом.
2. Экспортируй cookies, открой файл и скопируй весь текст.
3. В Vercel добавь переменную `COOKIES_TXT` и вставь туда этот текст, затем сделай Redeploy.

## Ограничения бесплатного Vercel

- Функция работает не дольше 5 минут, поэтому сайт скачивает ролики **до 10 минут** и **до 200 МБ** (настраивается переменными `MAX_MINUTES` и `MAX_DOWNLOAD_MB`). Для эдитов и Shorts этого хватает с запасом. 4K-видео весят много: если не успевает, выбери 1080p.
- Трафик на бесплатном тарифе ограничен (около 100 ГБ в месяц). Для личного использования и друзей этого достаточно.
- Тариф Hobby предназначен для некоммерческих проектов.

## Локальный запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt uvicorn
uvicorn api.index:app --reload
```

Сайт откроется на <http://localhost:8000>.

## Файлы

- [rater.py](rater.py): оценка кадров через Claude
- [public/](public/): сам сайт (HTML/CSS/JS) и файлы для установки как приложение
